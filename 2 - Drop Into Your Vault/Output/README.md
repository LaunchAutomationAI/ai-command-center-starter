# Output

Generated deliverables live here. Reports, exports, drafts, PDFs, presentations, anything Claude produces FOR you that isn't a permanent wiki article.

Examples:
- Weekly status reports (.docx)
- Client briefs (.pdf)
- Email drafts (.md)
- Spreadsheets (.xlsx)
- Presentation decks (.pptx)

You'll find files here after you ask Claude to generate something. Claude returns a `computer://` link in chat that opens the file directly.

This folder is yours. Move files out when you're done with them. Delete what you don't need. Claude won't touch files you put here manually.
